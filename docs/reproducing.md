# Reproducing the paper experiments

Install `python -m pip install -e '.[examples]'` from the repository root.
Every benchmark has `--help`, writes CSV results, and records arguments and
dependency versions in `run_metadata.json`. New runs go under `outputs/`;
the archived `paper_results/` files are never overwritten by default.

## Small checks

```bash
gwipg-paper --list
gwipg-paper all --quick
```

Quick runs check data preparation, solvers, metrics, and output writing. They
deliberately use very small iteration budgets and are **not** the numerical
results in the paper. Convergence warnings can be expected with those budgets.
The first SNARE-seq example downloads three small SCOT files, validates their
SHA-256 checksums, and caches them in `data/snare_seq/`. For offline use:

```bash
gwipg-paper snare --quick --offline --data-dir /path/to/cached/snare_seq
```

The examples are also available as `python examples/reproduce_paper.py ...`
and individually as `python examples/graph_alignment.py --help`, etc.

## Full runs

Full sweeps are substantially more expensive than quick checks. The complete
settings are in `src/gwipg/benchmarks/paper_presets.json` and are printed before
each run. Commands below write into `outputs/paper/full/<experiment>/`.

| Command | Paper experiment |
| --- | --- |
| `gwipg-paper gaussian` | Figure 1's Gaussian coupling comparison, n=30, seed 42 |
| `gwipg-paper graph` | Figure 2 and graph tables; n=100,200,300,400,500, 20 seeds |
| `gwipg-paper snare` | SNARE-seq n=250,500,1047, five seeds, 42 configurations |
| `gwipg-paper projection-cost` | Graph projection counts and timing, 20 seeds |
| `gwipg-paper inner-accuracy` | Fixed 250-cell instance, exponents 1.1,2.1,3.1,4.1 |
| `gwipg-paper spheres` | Nine sphere configurations, five independent samples each |

`gwipg-paper all` runs them sequentially. Supply `--output-dir` to choose a
different destination. The `gwipg-lowrank` command retains the exploratory
low-rank comparison; it is separate from the reported camera-ready experiments.

For stable timing comparisons, set BLAS thread counts before starting Python:

```bash
OMP_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 VECLIB_MAXIMUM_THREADS=1 gwipg-paper spheres
```

On Windows use the corresponding environment-variable syntax. Timings depend
on CPU, BLAS, threading, and dependency versions. The archived environment's
versions available during this cleanup are recorded in
`docs/reproduction-constraints.txt`; they are not proof of the environment used
for every historical run. That constraints file targets Python 3.12.

To use those versions in a fresh Python 3.12 environment:

```bash
python -m pip install -e '.[examples]' -c docs/reproduction-constraints.txt
```

## Protocol details

Graph experiments use the same seed list generated by
`np.random.default_rng(0).integers(0, 10**9, size=20)`, connected ER graphs
with edge probability 0.2, edge-flip probability 0.1, normalized shortest paths,
uniform marginals, and product initialization. The vectorized noise generator
preserves the original random-number sequence. Graph CSVs retain `PGD` as the
historical method name; plots label it `EPGD` as in the paper.

SNARE-seq follows the SCOT preprocessing and metrics. FOSCTTM is bidirectional;
the manuscript's LTA is the **chromatin-to-RNA** column `lta_x_to_y`, not the
average of the two LTA directions. Full-data seeds permute the same 1,047
cells, whereas the smaller runs also sample subsets. Successful CSV rows mean
the run returned finite values, not that all stopping tests were satisfied.

The archived SNARE-seq iPG settings were checked by rerunning n=250 and n=1047,
each with seed 0:
`expon=2.1`, `proj_tol_scale=0.05`, `proj_lr_const=1.5`,
`max_iter_proj=500`, `iter_check=5`, `lr_const=10*n`, and `tol=2.5e-4`.
This reproduces the archived loss, feasibility, outer count, and mean inner
count. The existing manuscript description saying `expon=3` for these runs
needs a separate correction; see [review notes](review_notes.md).

The inner-accuracy ablation is a different experiment: `tol=1e-4`,
`proj_tol_scale=1`, and the four specified exponents. It must not be confused
with the main five-run SNARE-seq sweep. CG retains POT's historical
`tol_rel=tol_abs=1e-9`; the old scripts' `tol` keyword did not set those values.

Sphere costs are **unnormalized squared Euclidean distances** between points
sampled on unit spheres. Convert the full squared-loss score by
`d_hat = (loss/16)**0.25`. The reference concerns continuous uniform measures;
errors combine sampling and optimization effects and are not certified
discrete optimality gaps. A packaged n=50, seed 0, S¹/S² run reproduced the
archived loss, feasibility, and projection counts.

Graph timing shares use ratios of mean component time to mean internal time;
SNARE-seq shares use means of per-run fractions. Full archived CSVs are supplied
so that these aggregation conventions can be inspected.

## Plots and archived results

```bash
python examples/plot_graph_results.py
python examples/plot_graph_results.py outputs/paper/full/graph/graph_alignment_summary.csv
```

The first command uses rounded numbers extracted from the original plotting
notebook, and writes five PDFs under `outputs/graph_figures/`. The second uses
fresh run summaries. `examples/archived_graph_figures.ipynb` retains the
original plotting style with saved outputs removed. Its embedded table is
rounded historical data, not a substitute for new raw solver outputs.

The original graph raw records were not present in the starting directory;
the repository includes their rounded summary and the existing figure assets.
For the additional experiments, selected raw and summary CSVs are copied
verbatim into `paper_results/`, with checksums and original paths in
`paper_results/manifest.json`. Pilot, tuning, smoke, and duplicate runs remain
in the local `results/` directory, which Git ignores.
